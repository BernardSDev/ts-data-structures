# TypeScript Data Structures

Core data structures built from scratch in TypeScript, with tests and benchmarks.
Part of my software engineering plan, Phase 1 (November 2026).

## Goals

- Understand how each structure works internally, not just how to use it
- Know the time and space complexity of every operation, and prove it with tests

## Roadmap

- [ ] Dynamic array (with resizing)
- [ ] Stack and queue
- [ ] Hash map (with collision handling and resizing)
- [ ] Linked list
- [ ] Binary search tree
- [ ] Min-heap / priority queue
- [ ] LRU cache

## Rules

- No built-in Map, Set or array helper methods inside the implementations
- Every structure has tests before it is marked done

## Running the tests

```bash
npm install
npm test
```
